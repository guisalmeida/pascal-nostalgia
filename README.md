# *__Pascal Nostalgia__* ✨

A memorable collection of Pascal programs from my early programming days.


### Prerequisites

You should have installed the `fpc` (Free Pascal Compiler) from [freepascal.org/download](https://www.freepascal.org/download.html).

For Debian/Ubuntu-based systems:
```sh
$ sudo apt install fpc
```

### Usage
In the project directory, you can run:

```sh
$ fpc fileName.pas && ./fileName
```
